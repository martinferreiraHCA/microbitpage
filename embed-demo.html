Página host de ejemplo — simula un generador de código de micro:bit (ml-microbit, MakeCode, un blog…) que embebe el panel y le manda datos con postMessage.

Esta página no tiene conexión propia; usa los botones para inyectar datos al panel embebido tal como lo haría una página que ya está conectada al micro:bit (por ejemplo, la clase detectada por un modelo de ml-microbit).

Mensajes recibidos desde el panel (lo que los bloques quieren enviar al micro:bit, variables y alertas):

Cómo se hace

const panel = document.querySelector('iframe').contentWindow;
panel.postMessage({ type: 'mbp:data', line: 'temp:23,luz:140' }, '*');   // una línea como la del micro:bit
panel.postMessage({ type: 'mbp:setVar', name: 'clase', value: 'saltando' }, '*');
panel.postMessage({ type: 'mbp:load', project: proyectoJSON }, '*');     // cargar un proyecto guardado
window.addEventListener('message', ev => {
  if (ev.data.type === 'mbp:send')  { /* enviar ev.data.text al micro:bit */ }
  if (ev.data.type === 'mbp:alert') { /* ev.data.alert = {level, message} */ }
  if (ev.data.type === 'mbp:var')   { /* ev.data.name, ev.data.value */ }
});
